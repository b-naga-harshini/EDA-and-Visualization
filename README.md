# Week 3 – Exploratory Data Analysis and Visualization

## Project Overview

This project focuses on **Exploratory Data Analysis (EDA) and Data Visualization** using a cleaned Supply Chain dataset. The objective is to understand the dataset, identify patterns and relationships, analyze distributions, and generate meaningful insights using Python.

## Objectives

* Understand the structure and characteristics of the dataset.
* Perform descriptive statistical analysis.
* Analyze numerical and categorical variables.
* Identify distributions and patterns in the data.
* Study relationships between important variables.
* Perform correlation analysis.
* Create meaningful visualizations.
* Generate insights that can support supply chain analysis.

## Dataset

The dataset contains supply chain information related to:

* Product details
* Pricing
* Sales and revenue
* Inventory and stock levels
* Suppliers
* Manufacturing
* Shipping and transportation
* Inspection and quality
* Costs
* Production

The cleaned dataset contains **24 variables** covering different aspects of supply chain operations.

## Tools and Technologies

* Python
* Pandas

* Seaborn
* Jupyter Notebook / Python

## Exploratory Data Analysis

The following analyses and visualizations were performed:

### Descriptive Statistics

Summary statistics were calculated to understand the central tendency, spread, and distribution of numerical variables.

### Histograms

Histograms were created for variables such as:

* Price
* Revenue Generated
* Number of Products Sold

### Bar Charts

Categorical variables were analyzed using bar charts, including:

* Product Type
* Transportation Modes
* Inspection Results
* Shipping Carriers
* Customer Demographics

### Box Plots

Box plots were used to examine the distribution and variation of:

* Manufacturing Costs
* Shipping Costs
* Defect Rates

### Scatter Plots

Relationships between numerical variables were explored using scatter plots:

* Price vs Revenue Generated
* Stock Levels vs Number of Products Sold
* Shipping Times vs Shipping Costs
* Production Volumes vs Manufacturing Costs

### Correlation Analysis

A correlation matrix and heatmap were created to identify relationships between numerical variables and understand the strength and direction of their associations.
